# Multiplayer on Cairn

A fork of [rwmt/Multiplayer](https://github.com/rwmt/Multiplayer), the multiplayer mod for **RimWorld**, made to run on the [Cairn launcher](https://github.com/Cairn-client/launcher).

## What we changed

- A Cairn pack: the mod and Prepatcher are published as a pack the launcher installs and updates.

The mod's own code and credits are its authors'. Everything else is as upstream; see [UPSTREAM.md](UPSTREAM.md) for the version this fork is based on.

## Play it

1. Install [Cairn](https://github.com/Cairn-client/launcher/releases/latest).
2. Open RimWorld in the Library, download the mod and press Play.

Enable the mods in RimWorld's mod list after installing.

Each release of this repository is the pack the launcher downloads.
